# 本地验收记录

当前 V3 已按用户要求替换为 2D 生成素材版；下方保留 V1/V2 历史证据。V3 的素材来源、实际画面与验收范围见 [art-v3.md](art-v3.md)。

日期：2026-09-21。执行子任务模型：GPT-5.6 Luna，Max。

## 交付范围

四席位浏览器牌局，席位可设为真人或真实大语言模型；服务端裁决规则，客户端使用 Three.js 正上方视角。每名真人在自己的画面中位于南面，男、女各两套程序化服装。轮盘采用每位玩家开局固定一个隐藏致死膛位，空枪后下一枪风险依次增加，发牌不重置膛位进度。淘汰者在桌边显示血泊。

AI 接口由房主在游戏设置里填写。未读取其他项目的模型凭证，未调用任何真实外部模型。接口适配测试与真实模型对局分开验收。

## 已观察到的真实浏览器行为

使用四个独立浏览器连接进入同一房间 KAZA9W，四个测试玩家分别选择男女两套服装。不是复制同一个玩家视图。

- 房主开放席位，三位真人分别加入后开局。
- 四个连接收到各自的手牌；轮到哪位玩家，哪位玩家才可出牌或质疑。
- 出一张真实目标牌后，下家质疑，翻牌显示真实，质疑者进入轮盘。
- 出一张非目标牌后，下家质疑，翻牌显示诈唬，出牌者进入轮盘。
- 空枪后重新发牌，目标牌和手牌更新，个人进度保留；观察到下一枪风险从 1/6 变为 1/5、1/4、1/3。
- 验收丁第四次受罚时通过按钮扣扳机中弹，自己的操作禁用；另一个玩家画面中对应人物消失、桌旁出现红色血泊，剩下三位继续发牌。
- 真人超时动作在公开记录中明确标记为“真人超时”，没有标为 AI。
- 房主及普通玩家刷新后恢复原席位和私有手牌。
- 桌面 1280×720、手机竖屏 390×844、低高度横屏 844×390 做了可见布局检查，并修复了人物遮挡、旋转后的圆桌变形和淘汰提示遮挡旁观的问题。

## 本地测试与真实模型的区别

自动测试使用确定性随机源、注入式接口响应和真实本地 Socket.IO 连接，验证规则、隐私边界、请求协议和状态转移。测试策略只存在于测试代码中，产品没有规则型 AI fallback。

真实模型验收仍待房主填写她自己的接口后执行。未验证具体网关的兼容性、模型的博弈表现、实际计费或实际响应速度，不把本地自动测试当作这些项目的证据。

## 部署状态和运行边界

本轮仅对 VPS 做只读预检，未上传、修改路由、安装或重启服务。候选独立进程拟运行于 `/opt/liars-tavern/current`，使用 `127.0.0.1:3279`，入口拟为 `https://aurexaevi.xyz/tavern/`。

房间和接口密钥只保存在游戏进程内存中；重启进程会结束现有房间，需要重新开桌填写接口。没有账号系统、跨进程存档或语音聊天。本轮没有修改 Aevi 生产代码、人格文件、聊天记录或用户数据。

上线脚本、固定文件清单和回滚步骤见同目录 `deployment.md`。上线仍需针对本次新服务和共用 Caddy 路由作明确确认。
